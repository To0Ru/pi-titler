# pi-titler 当前设计

> 只描述**当前已实现**的行为。行为改变时原地改写；讨论与理由见 `decisions.md`。

## 目标

* Pi 默认用第一条用户消息作展示名，`/resume` 列表难读。本扩展用独立的轻量标题模型，为每个会话生成描述**该会话具体任务**的标题（同一项目多个 Agent 共用 `AGENTS.md` 时也能区分）。
* 标题跟随用户主要语言，技术名词保留原文；按终端显示宽度限制，默认 40（约 20 个汉字）。

## 自动命名

前提：已明确配置标题模型、`autoNaming` 开启（默认）、会话尚无标题、不是未开启补命名的历史会话。

| 触发 | 行为 |
| :--- | :--- |
| 每条用户消息 `message_end` | 与主模型并行发起；任务明确则立即命名，含糊（问候、“看看项目”）允许返回 `NO_TITLE` |
| 每次 `agent_settled`（非 aborted） | 带上本轮助手最终回复开头与工具足迹再试，仍允许 `NO_TITLE` |
| 累计第 3 条用户消息 | 强制命名，不再允许 `NO_TITLE` |

* 命名成功后不再自动改名；用户可通过 `/titler` 手动重新生成。
* 用户消息不含助手与工具结果；琐碎确认（“好的/继续”）并入前段。
* 语义暂缓（`NO_TITLE`）不触发 30 秒冷却；真正失败（网络、超时、429）冷却 30 秒后等待下次自然事件重试。
* 关闭 `autoNaming` 后跳过全部自动入口；结果写入前再次检查开关。

## 手动重新生成

* `/titler` → “重新生成当前会话标题”，直接替换已有标题（含 `/name` 设置的），无二次确认；失败保留原名。不受 `autoNaming` 与历史开关限制。

## 取材（`context.ts`）

本地纯文本结构化摘要，自动与手动模式分开设计，发送纯文本而非 JSON 原文。

* **工具足迹**：只记操作与目标，不记参数正文与输出内容。同类合并计数（如：`修改 context.ts×3, ui.ts｜命令 npm test×2｜读取 README.md（准备动作）`）；失败调用标记 `(失败)`；用户 `!` 命令按 bash 足迹处理。
* **用户消息清洗**：剔除注入的 `AGENTS.md` 与环境块；围栏代码块折叠为 `[代码 N 行]`；压缩空白为单行。
* **排除项**：系统提示词、思考块、插件条目、`branch_summary`（被放弃分支的摘要）。
* **Token 预算制**：CJK 记 1 token，其余每 4 字符记 1 token；超预算单项跳过而非中断收集。
* **自动模式摘要（预算约 1,200 token）**：
  * 首条实质请求（≤600 字符）+ 后续消息（各 ≤300 字符）+ 助手最近回复（≤200 字符，仅 settled 时有）+ 工具足迹。
  * 若会话超长超出预算，自适应降级使用手动时间线结构，但仍使用自动模式提示词。
* **手动模式摘要（预算约 2,000 token）**：
  * 时间线（较早部分，按非琐碎消息分段，显示轮次与修改文件投入量，最多 8 段，超量合并更早段）+ 近期（最近 5 轮，含可见回复与精简工具）+ 早期 compaction 摘要（≤600 字符，预算有余时）+ 整体足迹。
  * 主线判定交给模型，忽略短暂插曲（1 轮无修改旁支），但若用户持续转向新任务则以新任务为准。

## 模型与失败

* 只用用户指定的标题模型；未指定时不命名。
* `fallbackToCurrentModel`（界面称“失败时改用：会话模型”）默认关闭；开启后标题模型失败或不可用时改用当前对话模型。
* 每个模型 15 秒超时、`maxRetries: 0`、`reasoning: "low"`、`cacheRetention: "none"`。自动命名失败冷却 30 秒，等下次自然事件重试；手动可立即重试。
* 同一份证据（哈希签名）去重；生成期间的新事件合并为一次待处理请求。

## 配置

* 全局：`getAgentDir()/titler.json`（默认 `~/.pi/agent/titler.json`）。字段：`version: 1`、`autoNaming`、`model: {provider, id} | null`、`fallbackToCurrentModel`、`nameHistoricalSessions`、`maxWidth`（8–120）。缺省字段按默认值读取。
* 保存时加锁、合并、原子替换；损坏或未知版本拒绝覆盖。
* 会话：未修改前实时继承全局；**首次保存任意修改时复制完整有效配置为独立快照**，此后整套不再跟随全局。“恢复全局配置”清除快照。通过 `pi.appendEntry`（`pi-titler:config`）持久化，不进模型上下文。
* 历史会话：首次见到无标记会话时，已有用户消息即视为历史会话，写入 `pi-titler:origin`。`nameHistoricalSessions` 默认关闭；开启后等下次对话事件再命名。

## `/titler` 菜单

* 首页：重新生成标题、设置。设置页 Tab 切换“本会话 / 全局”，显示本会话是继承还是独立配置。
* 统一 Pi 列表风格（边框、箭头、主题色）；Esc 逐级返回（模型 → 提供商 → 设置 → 首页）。
* 两列对齐（CJK 宽度），说明区固定两行，长模型名单行省略，边框高度不随选中项变化。
* 仅 TUI 模式可用；其他模式提示编辑配置文件。
